# CC0 wall material sources

The wall source sheets in this directory come from **Top Down Dungeon Pack** by
Screaming Brain Studios, downloaded from OpenGameArt.org. The pack is released
under CC0 / public domain; attribution is not required. `License.txt` is the
license file distributed with the original pack.

Source page: https://opengameart.org/content/top-down-dungeon-pack

These source sheets are sampled and recolored by
`tools/generate_maze_tilesets.mjs` to produce the game-specific atlases under
`assets/maze/<world>/tileset.png`.
